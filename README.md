# Воробьевский Синдикат — электромонтаж

Одностраничный сайт электромонтажной компании. Нижний Новгород и область.

## Что внутри

Один `index.html` без сборки и зависимостей плюс папка `assets`. Открывается двойным кликом, кладётся на любой статический хостинг как есть.

Ядро страницы — герой со скролл-видео: ролик привязан к прокрутке и разворачивает путь «от квартиры до завода». Телефон получает свой вертикальный ролик, снятый под портрет.

- `index.html` — вся страница: разметка, стили, скрипты
- `assets/hero-scrub.mp4` — горизонтальный ролик героя, 1920×1080
- `assets/hero-scrub-m.mp4` — вертикальный ролик для телефона
- `assets/g01…g12.jpg` — фотографии с реальных объектов
- `assets/why-1…6.jpg` — иллюстрации к блоку преимуществ
- `assets/logo-*` — логотип и вырезанный из него неоновый слой для загрузчика

## Локальный просмотр

Двойной клик по `index.html` покажет статичный герой: браузер запрещает `fetch` на `file://`, и ролик не загрузится. Чтобы увидеть скролл-видео, поднимите любой локальный сервер:

```
npx http-server . -p 8123 -c-1
```

## Что правится в одном месте

Телефон, почта, ссылка на карточку в Яндекс.Картах и ступени ценовой рейки лежат объектом `CONFIG` в начале скрипта.
